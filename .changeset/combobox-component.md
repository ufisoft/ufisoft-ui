Add `Combobox`: a text field with a filtered list for choosing one value from a long list, with accent-insensitive filtering, `sm`/`md`/`lg` sizes, `FormField` support and translatable messages. Built on Downshift and Floating UI (new dependencies `downshift` and `@floating-ui/dom`). The build now keeps `@floating-ui/*` and `downshift` external like the other runtime dependencies.
