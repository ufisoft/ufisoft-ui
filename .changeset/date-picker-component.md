Add `DatePicker`: a date field where users type the date or pick it from a calendar, with `min`/`max`, `sm`/`md`/`lg` sizes, `FormField` support, translatable names and format through `locale` (e.g. `tr` from `react-day-picker/locale`), and a hidden `yyyy-MM-dd` input for forms. Built on react-day-picker and date-fns (new dependencies `react-day-picker` and `date-fns`), kept external in the build like the other runtime dependencies.
