# Design tokens

Tokens are CSS custom properties prefixed with `--ufi-`, defined in two layers:

```text
Primitive tokens   src/tokens/primitives.css   raw values       --ufi-blue-600, --ufi-space-4
      ↓
Semantic tokens    src/tokens/semantic.css     roles            --ufi-color-action-primary-bg, --ufi-space-md
      ↓
Components         *.module.css                use semantic tokens only
```

- **Primitives** have numeric suffixes and no meaning. Only semantic tokens reference them.
- **Semantic** tokens describe a role. Components use only these, so a theme (e.g. dark mode) overrides one layer.
- In application CSS, use semantic tokens too:

```css
.toolbar {
  padding: var(--ufi-space-sm) var(--ufi-space-md);
  border-block-end: var(--ufi-border-width) solid var(--ufi-color-border-subtle);
}
```

## Spacing

4px grid. `--ufi-space-{size}`: `none` 0 · `2xs` 4px · `xs` 8px · `sm` 12px · `md` 16px · `lg` 24px · `xl` 32px · `2xl` 48px.

Control heights (shared by `Button` and `Input`): `--ufi-control-height-{sm|md|lg}` = 32 / 40 / 48px.

Container widths (`Container`): `--ufi-container-{sm|md|lg|xl}` = 640 / 768 / 1024 / 1280px, the breakpoint widths.

## Radii, shadows, z-index, motion

| Category | Tokens                                                                                     |
| -------- | ------------------------------------------------------------------------------------------ |
| Radius   | `--ufi-radius-{none\|sm\|md\|lg\|full}`                                                    |
| Shadow   | `--ufi-shadow-{sm\|md\|overlay}`                                                           |
| Z-index  | `--ufi-z-{base\|dropdown\|sticky\|overlay\|modal\|toast\|tooltip}` (non-top-layer content) |
| Duration | `--ufi-duration-{fast\|normal\|slow}` = 100 / 200 / 300ms                                  |
| Easing   | `--ufi-easing-default`                                                                     |
| Focus    | `--ufi-focus-ring-{width\|offset\|color}`                                                  |

## Breakpoints

CSS variables cannot be used inside `@media`. Use the JS export, or the literal values in CSS:

```ts
import { breakpoints } from '@ufisoft/ui';
// { sm: '640px', md: '768px', lg: '1024px', xl: '1280px' }
```
